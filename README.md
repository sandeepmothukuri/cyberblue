# ⚠️ **EDUCATIONAL & TESTING ENVIRONMENT ONLY** ⚠️

CyberBlue is a containerized cybersecurity learning platform combining SIEM, DFIR, CTI, SOAR, network analysis and threat-hunting tooling for isolated lab use.

---

## 🎯 About CyberBlue

CyberBlue provides a hands-on environment for learning SOC operations, threat hunting, incident response and security automation using open-source security tools.

## 🛡️ Security Tools Included

- Wazuh, Suricata, EveBox
- Velociraptor, Arkime, Wireshark
- MISP, MITRE ATT&CK Navigator
- Shuffle, TheHive, Cortex
- CyberChef, Portainer, FleetDM, Caldera
- YARA and Sigma rule collections

---

## 🚀 Quick Start

```bash
git clone https://github.com/sandeepmothukuri/cyberblue.git
cd CyberBlue
chmod +x cyberblue_install.sh
./cyberblue_install.sh
```

## 🔒 Security Considerations

This is a training platform, not a production security solution. Deploy only in an isolated environment, change default credentials before use, and never process real sensitive data.
